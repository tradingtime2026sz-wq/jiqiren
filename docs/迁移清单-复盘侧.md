盘中提醒（alerts.py）的部分见 `docs/盘中提醒-v0.md` 末尾，由 WQ 主会话维护。本清单只管复盘这一侧。搬到 Mac Studio 时两边一起迁。

| 项 | 位置 | 说明 |

## 新机器上要有的

- 富途 OpenD 在跑并已登录（127.0.0.1:11111）；第一次跑会按需拉日线和分钟线。
- `~/Codes/option-ab-lab/pool.csv`：插针速查表的票池；`option-ab-lab/data/1m` 只在重跑回测时需要。
- 时区必须是美东：每日复盘的 launchd 用的是本机时间 16:20，时区不同要改 plist 里的小时。
- 机器用户名若不是 vock，plist 和脚本里的 `/Users/vock/...` 路径要改。

## launchd

- `~/Library/LaunchAgents/com.vock.tiger-review-daily.plist`：周一到周五 16:20，`python -m tiger_review auto --scheduled`。
- 新机器装好并跑通一次后，**在笔记本上执行 bootout 停掉旧任务**，否则两台机器都会同步、都会复盘。

```bash
launchctl bootout gui/$(id -u)/com.vock.tiger-review-daily
```

## 搬过去后要改的一处

- 复盘完成的提醒现在用的是 macOS 系统通知（`osascript display notification`），Mac Studio 若没人看屏幕就等于没发。迁移时改走 Telegram（复用 `scripts/tg_send.py`），**发到哪里待 WQ 决定**：10-24 WQ 定盘中提醒和作战卡只发群「Happy Trading」，但复盘通知含个人账户盈亏，发群等于把账户结果给群成员看，所以不照搬，迁移前先问 WQ（私聊、群、或群里只发不含金额的版本）。群 id 从 `~/.config/telegram/chat_id` 读，不写进代码。
